A program that writes exactly one deadpan one-star review of gravity: "One star. Gravity has never missed a day of work and has never once caught anything I dropped. Flawless attendance, zero helpfulness." The sharpest true grievance — gravity shows up every day without fail and has never once caught anything you dropped — filed in earnest, with the sting arriving in the last few words like a performance review.

## Run it

```sh
python3 main.py
```
